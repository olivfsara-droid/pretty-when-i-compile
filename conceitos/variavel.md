# Variável

## O que é

Uma variável é um nome que usamos no programa para guardar e acessar um valor.
Ela funciona como uma identificação para sabermos o que está sendo armazenado e podermos usar esse valor depois no código.

## Minha analogia

Para mim, uma variável é como um pote de tempero.
O nome da variável seria a etiqueta do pote, e o valor seria o que está dentro dele.

Por exemplo, se o pote tiver uma etiqueta "tempero", podemos colocar orégano dentro dele.
Depois podemos trocar o conteúdo por outro tempero sem mudar o nome do pote.

## Exemplo

```javascript
let tempero = "orégano";

tempero = "pimenta";
